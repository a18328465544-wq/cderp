# 资金调拨 API Gap

## 当前缺口

1. **没有专用调拨列表接口**：正式页暂时通过权限裁剪后的 `/api/gpu_erp/finance/account-transfers` 读取 `accountTransfers`，筛选和分页在前端执行。记录量扩大后应补充服务端分页、日期、账户和经办人筛选接口。
2. **没有专用汇总接口**：页面的金额卡片基于已加载权限集合计算，不宣称为服务端全量汇总。
3. **删除媒体不适用**：资金调拨没有凭证图片字段，V2 不新增上传能力。

## 已确认不是缺口

- 新增、编辑、删除接口已经存在，不需要后端扩展。
- `receivedAmount = amount - fee` 与账户余额/流水原子更新由现有后端负责。
- 没有 `settlement_accounts` 权限时，服务端会将账户余额字段归零；V2 不把前端隐藏当作安全边界。
