## 3. 额外发现并修复的实际问题

### 活动开单 Tab 可能静默丢弃草稿

新建采购/销售页面需要允许正常切换 Tab 并保留草稿，因此不能仅依赖路由离开拦截器。原实现只对后台 Tab 显式检查 dirty 状态，活动 Tab 关闭依赖页面拦截，导致新建表单可能静默关闭。

修复方式：活动和后台关闭均先使用现有未保存确认框；继续编辑保留草稿；确认放弃只对本次关闭赋予确认意图；导航成功后释放页面，失败时保留草稿。普通切页仍保留现有行为。编辑页确认后不会重复出现第二个离开确认框。

### 退货对账的“全部”过滤器误过滤所有记录

统一识别 `all` 与空值的“全部”含义，并保留具体状态过滤行为。新增针对性测试。没有扩大查询范围：原来的采购/销售各前 100 条限制仍然存在，现在明确说明范围，不能将当前汇总解释为数据库全量对账结果。
