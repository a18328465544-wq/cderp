# 权限规则

## 五类权限

1. 页面访问权限：能否进入页面。
2. 操作权限：能否创建、编辑、删除、导出或提交。
3. 字段权限：成本、利润等敏感字段是否进入前端模型。
4. 数据权限：可见门店、仓库、主体范围由服务端决定。
5. 跨模块依赖权限：一个流程读取另一个模块数据所需的菜单权限。

## 销售开单当前依赖

| 能力 | 当前权限 |
| --- | --- |
| 进入销售开单 | `sales_add` |
| 客户查询 | `crm` |
| 库存候选查询 | `inventory` |
| 收款账户查询 | `settlement_accounts` |
| 成本 | `showCost` |
| 利润 | `showProfit` 且成本可见 |

## 规则

- 权限字段只能通过 Permission Adapter 读取，不猜测字段名称。
- 隐藏按钮不能替代接口权限；401/403 必须统一转换为 `ApiError`。
- 未授权成本和利润不得先进入页面 Domain Model 再靠 CSS 隐藏。
- 跨模块依赖和 403 降级必须写入 Feature Contract / Gap。
- 无查看权限时不渲染业务数据、表格或详情内容。
