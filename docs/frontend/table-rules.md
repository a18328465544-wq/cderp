# 表格规则

## 统一 DataTable

业务列表统一使用 `ErpDataTable` + TanStack Table。模块只提供：

- Columns
- Filters
- Toolbar
- Row Actions
- 数据查询和权限配置

禁止复制一份新的万能表格或在页面内实现第二套分页、排序和空态。

## 必备状态

- 首次 Loading
- 保留旧数据的后台刷新状态
- Empty
- Error + Retry
- 无权限
- 服务端分页
- 服务端排序
- 行选择和批量栏（只有后端契约支持时启用）
- 列显隐、密度和用户偏好

## 服务端原则

如果接口不支持筛选、排序或分页，必须标注降级和 API Gap；不能在大数据量上伪装成服务端处理。列定义不能把成本、利润或敏感字段绕过权限。

## 库存参考

库存正式页使用 `/api/inventory/items` 的分页和排序，型号、成色、入库日期在接口未支持时保持禁用并明确提示；详情通过独立 Query，不从表格行拼接完整详情。
