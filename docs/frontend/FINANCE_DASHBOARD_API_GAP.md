# Finance Dashboard API Gap

| 缺口 | 当前影响 | V2 降级 | 后端未来建议 |
| --- | --- | --- | --- |
| 驾驶舱接口仍返回领域集合而非聚合值 | `/api/finance/dashboard` 已裁剪到财务依赖集合，但数据量仍随业务增长 | 单次请求后立即在 Adapter 投影，不复制到 Zustand | 在 SQL 层按日期和权限直接返回聚合指标 |
| 领域快照仍携带跨模块明细 | `publicState` 裁剪阻止越权集合，但传输量仍高于汇总接口 | 只消费最小 Domain Model | 在 SQL/序列化层按指标权限仅返回聚合值 |
| 无权限集合以空数组/金额置零返回 | 单凭响应无法区分真实 0 与无权限 | 结合真实会话权限显示“不可用”，不伪造 0 | API 返回明确 capability/field visibility 元数据 |
| 没有服务器业务日期元数据 | 日期边界只能使用门店时区工具 | 固定使用 `Asia/Shanghai` 的现有 store time 工具 | 汇总响应返回 `businessDate` 与时区 |
| 没有每日库存占用快照 | 历史期资金周转率只能估算期初占用 | 明确标记为估算；无成本权限或样本不足时隐藏数值 | 保存日终资金/库存占用快照并返回正式周转指标 |
| 账户详情、记账与复核仍在旧子路由 | 驾驶舱不能在同页执行写操作 | 仅导航到现有权限保护路由 | 后续逐页迁移，不扩展本轮范围 |
