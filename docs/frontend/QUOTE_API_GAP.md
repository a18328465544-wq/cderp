# 行情参考 API Gap

## 已解决

- 行情页读取已切换到受登录权限保护的 `GET /api/market-quotes` 专用快照接口，不再误用商品库分页接口。
- 服务端统一按账号权限投影行情价格和历史点；旧的 `/api/state` 兼容路径也使用同一投影，避免只靠前端隐藏。
- 行情快照请求在状态修订变化时只刷新 `marketQuotes` 与 `inventory`，不使用过期进程缓存。

## 尚存边界

1. 创建行情时后端会生成独立的 `SP-MOCK` productId；当前没有商品模板绑定选择契约。V2 保持真实接口行为，不伪造绑定关系。
2. 已上传行情没有独立详情接口。详情抽屉只展示列表快照中的真实字段。
