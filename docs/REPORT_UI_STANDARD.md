# 报表系统 UI 规范

本规范以“账户流水报表”设计稿为基准，适用于销售利润、资金流水、收款、支出、日结、库存分析以及后续新增的经营报表。它定义的是信息结构和交互规则，不是静态截图数据；所有数字必须由当前筛选范围内的真实状态计算。

## 1. 固定页面骨架

报表页面按以下顺序组织，禁止随意调换导致用户需要重新寻找操作入口：

1. **报表标题与操作区**：标题、简短口径说明、收藏（可选）、分享/订阅/更多/导出/全屏等真实操作。
2. **报表页签**：报表、明细、汇总和相关分析入口。页签要么导航到真实区域，要么跳转到对应页面，不能使用无效按钮。
3. **筛选区**：日期范围和快捷日期、业务维度筛选、搜索、已选条件、清空和查询。筛选改变后指标、图表、排行和表格必须同步变化。
4. **指标卡**：4—6 张同宽卡片；每张包含名称、主值、口径/对比和语义色图标。金额、数量、比率使用真实数据，空数据明确显示 0 或暂无数据。
5. **分析区**：趋势图、构成图、排行/漏斗等至少两个互补视角。每张图必须有标题、单位、时间范围、图例、精确汇总和空状态。
6. **明细表**：表头、筛选结果数量、导出/列设置、稳定操作列、空状态和分页。明细表允许横向滚动，但页面整体不能被撑宽。
7. **汇总与说明区**：按账户/客户/商品/员工等维度汇总，说明统计口径、数据更新时间、相关报表和下一步操作。

## 2. 页面布局

- 主内容使用 `ErpAnalyticsPageFrame`/`AnalyticsFrame`；标题和页签不重复渲染。
- 分析区使用 2—3 列自适应网格；有异常、同比、快捷操作时放在右侧窄栏。
- 报表首屏在 1440px 下应同时看到标题、筛选、指标卡和第一行分析；不要通过大块空白制造“高级感”。
- 窄屏下按“标题 → 页签横滚 → 筛选折叠/横滚 → 指标两列 → 分析单列 → 明细横滚”降级。
- 卡片统一使用 `src/styles/tokens.css` 的边框、圆角、白底和轻阴影；区块标题与操作同一行对齐。

## 3. 数据与交互

- 日期筛选使用门店时区 `storeDate` 和 `ErpDateRangePicker`；快捷范围至少支持今天、昨天、近 7 天、近 30 天、本月、上月、今年和全部。
- “查询”不能只改变选中样式；若页面采用即时筛选，应隐藏无意义的查询按钮，或让按钮明确重新计算/请求数据。
- 已选条件必须可读，清空后恢复全部数据；筛选、分页、页大小变化后明细页码回到第 1 页。
- 图表数据必须与表格使用同一份过滤结果；禁止用固定示例数字、固定百分比或静态排行填充。
- 金额颜色统一：收入/收款/到账使用 `--erp-color-income`（绿色），支出/付款/成本/手续费使用 `--erp-color-expense`（红色），净额/中性汇总使用 `--erp-color-net`（蓝色），待处理/逾期/异常风险使用 `--erp-color-risk`（橙色）。红色表示已发生的负向结果，橙色不代替支出；正负号、文字和图例仍必须同时保留。
- 只展示业务上可解释的指标。没有“收款方式”“客户”等字段时，改用真实存在的业务维度，不捏造字段。
- 导出只导出当前筛选结果；导出按钮在无数据时给出明确通知。
- 快捷操作必须调用现有导航或业务动作，并遵守权限；不能留下点击无反应的按钮。

## 4. 共享组件

```tsx
<ErpAnalyticsPageFrame>
  <ErpPageHeader
    title="账户流水报表"
    subtitle="说明统计口径和更新时间"
    actions={<ReportActions onExport={handleExport} />}
  />
  <ReportFilterPanel>{filters}</ReportFilterPanel>
  <div className="grid ..."><ReportMetricCard ... /></div>
  <ReportSection title="趋势">...</ReportSection>
</ErpAnalyticsPageFrame>
```

组件位置：`src/components/common/ErpPageFrames.tsx`、`src/components/common/page-frames/AnalyticsFrame.tsx`。财务利润、提成、行情和 AI 分析页面已经使用这套骨架；新报表必须优先复用这些组件，不要在页面里重新定义标题栏、指标卡、区块容器和页签样式。

## 5. 交付检查

- 真实数据、权限和空状态已覆盖。
- 筛选会同步影响指标、图表、排行和明细。
- 1440px、1024px、390px 无遮挡和无意横向溢出。
- 所有按钮、页签、导出、分页、清空和快捷入口有行为或明确禁用说明。
- `npm run lint`、相关单元/渲染测试和 `npm run build` 通过。
