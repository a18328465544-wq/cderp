# Frontend V2 隔离环境

这个工作树只用于新版前端开发，线上旧版本保持不变。

## 端口

- 前端：`http://localhost:3010`
- 测试 API：`http://127.0.0.1:3011`
- 生产 API `3001` 不允许作为本地 V2 的默认代理目标。

## 运行规则

1. 先准备独立测试数据库，再启动测试 API。
2. 使用 `npm run dev:api:v2` 启动监听 `3011` 的 V2 测试 API，或直接运行 `npm run dev:full`。
3. V2 前端通过 `.env.local` 代理到 `3011`，不会直接写生产 API。
4. 页面迁移按销售开单、库存、CRM、财务、采购的顺序进行。
5. 每个页面必须通过权限、金额、库存和响应式验收后，才能替换旧页面。
