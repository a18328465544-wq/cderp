# ERP 表格交互与对齐统一设计

## 目标

统一 ERP 全部业务表格的三项基础行为：横向滚动、拖动调整列宽、表头与单元格文字居中。保持现有业务数据、接口、筛选、分页、固定列和导出逻辑不变。

## 设计原则

- `TanStackDataTable` 作为统一表格能力入口，默认启用横向滚动和列宽拖动。
- 旧 `DataTable` 继续作为兼容入口，但最终渲染复用 `TanStackDataTable`。
- 尚未迁移的手写表格使用公共 `erp-table` / `erp-entry-table` 样式，不在每个页面重复实现滚动和对齐。
- 居中仅作用于表格表头、表格单元格及单元格内部录入控件，不影响页面表单、弹窗正文和普通卡片。
- 固定列继续使用 `position: sticky`，表头层级高于表体；固定列背景与所在行 hover 状态同步。

## 公共表格行为

### 横向滚动

- 表格外层统一使用可横向滚动容器。
- 表格宽度由可见列宽总和决定，内容不足时占满容器，内容超出时出现横向滚动。
- 滚动条使用现有低噪声样式，不占用额外的数据行视觉空间。

### 列宽拖动

- 默认启用列宽拖动，最小列宽保持 80px，业务列可通过 `minWidth` 覆盖。
- 拖动手柄只在表头悬停或正在拖动时清晰显示。
- 调整后的列宽继续通过现有 `localStorage` 表格偏好保存。
- 固定列偏移根据调整后的真实列宽重新计算，避免拖动后错位。

### 居中规则

- 所有 `th`、`td` 默认 `text-align: center`，内容容器统一水平居中。
- 金额、数量、状态、时间、编号、备注和操作列均居中。
- 单元格内的 `input`、`select`、只读值同步居中。
- 长文本仍使用省略号和 title/详情查看能力，居中不改变溢出规则。

## 遗留手写表格

- 采购开单、销售开单、组装拆卸、扫码记录、单据详情等手写表格接入公共表格类。
- 清理表格范围内的 `text-left`、`text-right`，统一改为居中；非表格区域不处理。
- 手写表格外层统一横向滚动，并保留现有 sticky 商品列和操作列。
- 不把纯布局网格或统计卡片误判为业务表格。

## 修改范围

- `src/components/TanStackDataTable.tsx`
- `src/components/DataTable.tsx`（仅在兼容层确有需要时调整）
- `src/index.css`
- 仍使用原生 `<table>` 的业务组件，例如采购、销售、组装拆卸、扫码和单据详情组件
- 表格渲染与公共样式相关测试

## 验证

- 运行 `npm run lint`、`npm test`、`npm run build`。
- 检查整体库存、单卡/SN 库存、商品库、采购单据、销售单据、库存进出明细。
- 检查采购开单、销售开单等可编辑表格。
- 验证横向滚动时固定列不消失、表头不被覆盖。
- 验证拖动列宽后刷新页面仍保留宽度。
- 验证表头、内容、输入框和操作按钮均居中且无文字遮挡。

## 非目标

- 不修改业务逻辑、接口、数据结构、分页口径和库存计算。
- 不重写页面 UI，不迁移新的表格库。
- 不改变现有筛选、导出和列显示设置。
