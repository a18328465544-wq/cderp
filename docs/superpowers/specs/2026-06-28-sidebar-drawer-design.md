# ERP 一级模块与二级浮层菜单设计

## 目标

将当前全部展开的侧边栏改为常驻一级业务模块，并通过点击一级模块打开小型二级功能浮层。保留现有页面、权限和 route ID，不创建没有对应页面的入口。

## 结构

- 一级侧栏固定为 160px，只保留七个业务模块的文字、箭头和必要内边距。
- 二级菜单为 188px 的白色小浮层，从当前一级菜单右侧（距左 160px）弹出，显示当前模块下用户有权限访问的页面，不推动主内容布局。
- 菜单配置使用嵌套模块结构，同时保留扁平菜单导出供权限系统兼容。

## 交互

- 点击一级模块时打开或切换二级浮层，再次点击当前一级模块关闭浮层。
- 点击二级菜单沿用原有 `setTab(id)`，随后关闭浮层。
- 点击页面空白遮罩或按 Escape 关闭浮层。
- 当前页面所属模块始终高亮，当前二级页面使用浅蓝背景、蓝色文字和左侧蓝色竖线。

## 边界

- 不修改业务页面、状态结构和接口。
- 不增加不存在的独立页面。
- 无权限的二级菜单与空模块不显示。
