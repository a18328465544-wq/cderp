# 统一下拉选择器规划

> 状态：进行中（基础组件已落地，旧页面按业务优先级渐进迁移）

## 目标

统一 ERP 内所有下拉选择的视觉、键盘操作和选中反馈，避免浏览器原生 `<select>` 在不同系统上出现不一致的蓝色菜单、字体和圆角。以后新增下拉选择默认使用 `src/components/ui.tsx` 的 `DropdownSelect`，不再直接创建原生 `<select>`。

## 组件约定

- 组件位置：`src/components/ui.tsx`
- 组件名称：`DropdownSelect`
- 数据接口：`options: [{ value, label, disabled? }]`
- 受控值：`value` + `onChange(value)`
- 兼容迁移：旧页面可以继续传入 `<option>` 子节点，`FilterSelect` 会自动转为统一组件
- 视觉：40px 普通控件、36px 紧凑筛选控件、8px 圆角、slate 边框、蓝色聚焦和选中态、白色浮层、轻量阴影
- 交互：点击/Enter/空格打开，↑/↓/Home/End 键盘移动，Enter 选择，Esc 或点击外部关闭
- 可访问性：按钮使用 `role="combobox"`，菜单使用 `role="listbox"`，选项提供 `aria-selected`
