# 手机工作台 V2：参考图实施

2026-10-08。本轮仅本地实现与验收，未发布、未推送，未连接生产数据库。V2 取代 V1 的手机导航、列表呈现和销售/采购步骤；其余业务与保活边界延续。

## 对照范围

| 参考屏幕 | 现有系统实现 | 保留的业务边界 |
| --- | --- | --- |
| 首页 | 今日/本周/本月经营概览、待处理、四个快捷操作、最近业务 | 真实授权数据；不加载桌面 AI 图表，不填假指标 |
| 销售开单 | 客户/商品选择、数量步进、价格编辑、底部下一步；结算另一步 | 型号库存占用，出库才绑定 SN；原金额/权限/重复提交校验 |
| 客户选择 | 全屏搜索、最近客户排序、S 级/联系人信息、原快速创建 | 同一查询和选择对象，不按展示文字反推关联 |
| 库存列表 | 搜索+扫码、分类横条、紧凑商品记录、排序面板 | 同一服务端过滤/状态/分页；型号与 SN 视图在统计面板 |
| 商品详情 | 全屏返回、真实图片或紧凑占位、价格、属性行、实际链路 | 不新增假调库存/直接售出动作；成本按原权限 |
| 扫码 | 全屏相机区域、失败说明、手工编号回填 | 原识别与流清理；不自动入账，未新增离线模式 |
| 采购开单 | 来源/商品选择、原新建商品窗口、数量步进、结算/附件 | 提交后仍待检测，不假装直接入库 |
| 订单详情 | 身份/状态、商品、结算、折叠补充信息、底部真实操作 | 原编辑安全策略、收付款、不可删约束 |
| 客户详情 | 核心 S 标记、往来概览、联系跟进、折叠档案、原编辑窗 | 不伪造交易历史/联系人头像或额外接口 |
| 我的 | 实际账号/角色、六个常用授权任务、功能查找、退出 | 管理配置仍桌面；不添加假的通知、帮助、设置 |

质检、出库和采购/销售退货延续原业务能力。2026-10-08复审进一步重做质检入库手机呈现：全新单步SN、二手SN→检测→确认、实时成色、可展开的共享入库设置及只读摘要、持续返回入口、底部并排确认。详见根目录`design-qa.md`最新复审，上一轮截图不替代本轮证据。

## 导航归属与入库入口（本轮修正）

- 库存、质检、商品、组装和售后属“库存”；采购/销售单、出库、退货和订单池属“开单”；客户和CRM属“客户”；财务、行情、经营分析属“首页”。“我的”仅在个人面板打开时高亮，不接管未匹配的业务页面。
- 库存列表提供已有授权的质检入库/扫码出库入口；开单菜单按创建、仓库、退货、已有单据分组。采购退货的创建动作去原new路由，原桌面列表入口不改。
- 移动标签在中央navigation配置管理，保留桌面菜单名、权限ID和路由。检测员没有库存权限时主入口可指向已有授权的质检页；不授予新权限。旧vendors→客户列表沿原权限规范化。
- 手机错误提示在动作栏上方只显示1条，不占据返回按钮；桌面通知保持原位置和条数。所有字段仍由原表单、校验与mutations控制。

## 实施约束

- 小于 768px 为手机；768–1023px 平板主从/完整卡片；1024px 起桌面表格。
- UI 适配复用同一控制器，不创建第二套订单、DTO、金额和库存算法。金额和数据沿用全局等宽数字、Inter/PingFang 字体令牌。
- 只有已打开任务保活，上限 10；未打开页面不预加载。普通切换保留内容；关闭/淘汰脏任务继续确认。没有新承诺刷新、浏览器被杀或离线自动重提单。
- 所有可用主操作使用至少 44px 触控面积。折叠的可选字段继续保持注册，图片上传阻塞和权限错误不能被隐藏。
- 服务端错误不清空草稿；输入和搜索维持原任务归属。关闭态下拉列表不能导致底栏消失。
- 「我的」作为一级 Tab 保留底部导航，背景页面不可交互；直接切换库存/客户等即可退出。搜索内快速新建待选择窗口关闭完成后打开系统原有新建商品窗口，不另建创建表单。
- 不改账务、质检、退货、采购库存、销售出库等状态机，不改生产配置和认证。

## 本地验收与复现

- `python3 scripts/mobile-preview-server.py`：仅 127.0.0.1:3020，优先读取本地 dist；API 使用明确模拟记录，业务写请求统一失败。可在浏览器验证失败后保留输入，不可能写真实单据。3020 不是生产后端。
- `npm run lint`、`npm test`、`npm run build`、`npm run check:performance` 使用现有门禁。单元回归增加只读记录、真实图片、数量边界、关闭态底栏、搜索适配共享和客户导航分类。
- `scripts/browser-mobile-workbench.py` 已更新新导航和两步录单的测试契约；只允许本地，继续覆盖草稿、幂等、失败、回车保护、桌面四行及检测/退货/出库。其完整自动化运行状态见根目录 design-qa.md，不把“更新脚本”当作“运行通过”。
- 本轮直接浏览器验收与证据见 `design-qa.md`。视口模拟无法证明 iOS/Android 实体相机、软键盘、扫码解码率；发布前需真机确认这些硬件边界。
