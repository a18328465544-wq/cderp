# 全页面移动端整改

本轮仅本地实现、验收；没有发布生产。桌面页面、业务规则、权限、单据状态和金额计算保持不变。

## 设计依据

- [Shopify Mobile](https://help.shopify.com/en/manual/shopify-admin/shopify-app)：手机按业务任务组织；搜索和扫码直接进入现有业务。
- [Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)：五个稳定目的地，切换保持状态；真正的模态任务才覆盖导航。
- [Linear Mobile](https://linear.app/docs/get-the-app)：列表、清晰层级和少量主要操作，复杂功能渐进展开。
- [Shopify 库存扫码](https://help.shopify.com/en/manual/shopify-admin/shopify-app/inventory-scanner)：扫码是库存工作流的入口，不另造一套数据源。

## 顺序与边界

1. 手机主导航与完整功能入口：沿用 canonical 菜单及权限，开单/我的成为稳定入口，原页面保持挂载。
2. 共享页面骨架：紧凑标题、主要操作、更多操作面板；报表指标双列；筛选、排序、分页和详情保持可达。
3. 所有列表：业务化列表行或紧凑记录卡，不在手机重复输出整张桌面表；所有字段和动作仍可展开。
4. 写入工作流：采购、销售、退货、质检及编辑保持同一表单、草稿与校验；手机步骤和底部操作避免遮挡。
5. 详情、设置、财务：单列内容、完整文本、全屏详情、可滚动弹窗；不以隐藏功能充当适配。
6. 逐路由实测：320/390/430 手机、768 平板、1440 桌面，真实可见尺寸和截图；本地模拟数据、业务写入阻止。

## 路由清单

首页；库存；商品库；组装拆卸；质检；行情；AI；订单池；售后。

销售列表/新建/详情/编辑/出库；采购列表/新建/详情/编辑；采购退货列表/新建；销售退货列表/新建。

CRM/客户列表/新建客户/供应商。

财务总览/账户/流水/收入/支出/调拨/毛利/月结/退货核对/采购提成/销售提成/往来资金。

设置入口/员工权限/日志/备份；登录、无权限、错误与无数据状态。内部设计系统不属于业务验收路由。

## 当前审查证据

390×844 首屏已捕获：`/private/tmp/erp-mobile-v2-evidence/audit-before-home-390.jpg`、`audit-before-more-390.jpg`、`audit-before-profit-390.jpg`。

- 功能被手机专用 allowlist 再次过滤：已有权限也无法到达账户、利润、设置等入口；应消除额外过滤而非放宽服务器权限。
- “我的”默认仅六个入口，缺少业务分组；“开单”被做成模态动作，导航不连续。
- 报表三个核心指标在手机仍为三个大卡片，占满首屏；标题操作右栏堆叠，搜索被推到屏幕底部。

采购编辑首轮测试用了错误的模拟 ID，显示的是数据不存在，不能据此归因为业务缺陷。使用 fixture 中 `CG-MOBILE` 重新验证。

## 验收记录

### 已完成

- 移除手机菜单额外 allowlist；“我的”按七个业务组呈现全部已授权功能，并可搜索。没有增加任何服务端权限。
- “开单”和“我的”保持底部导航可用；背景页面不可误操作。五个主导航在 390px 实测各约 74.8px，左右边界 8–382px，对齐一致。
- 手机标题保留一个主要操作，其余放入共享操作面板；桌面标题仍输出原操作组。
- 列表首屏只展示关键字段，其余可展开；操作集中在共享面板，图标操作有可见文字。分页简写为 `20/页` 等，数值和分页行为不变。
- 报表搜索前置，主要指标紧凑双列，更多指标展开；财务列表设置集中到共享面板。
- 采购/销售编辑及组装表单接入既有分步流程；字段保持挂载，未复制表单、DTO、状态或提交逻辑。
- 客户/销售商品的手机选择入口改为明确的选择按钮，点击进入既有搜索弹层，不再用只读输入框冒充搜索。
- 手机表单说明完整换行；图标按钮最小触控区 44px；无权限页面能返回确实有权限的页面，而不是强制返回可能无权访问的首页。

### 实际操作验收

- 采购：选择客户、选择商品、增加数量、进入结算，模拟提交冲突显示明确反馈；切到库存再通过开单返回，商品、2 件数量、¥200 和失败提示都保留。
- 销售：客户/商品选择、增加数量、进入结算、选择账户、提交失败反馈可用；最终版本商品入口为选择按钮，已再次打开确认。
- 退货：原采购单搜索 → 库存搜索 → 结算 → 确认/原因填写，底部操作可达。此 fixture 的批量权限关闭，不能据此声称已完成多件实际提交验收。
- 质检：全新仅 SN 即可启用确认，可展开质保/库位/包装；二手按 SN → 检测 → 确认走通，实际测试字段和摘要一致。返回待办保留当前录入，切换实物前仍要求确认放弃。
- 列表：商品操作 → 既有商品编辑窗口 → 取消返回；操作文字可见；切换 `50/页` 会更新 URL，全部隐藏字段可展开/收起。
- 日期：320px 筛选面板中的日期弹层可滚动，选择“今天”并应用后 URL 开始/结束日期均变为当天，返回正常导航。
- 弹窗：商品模板编辑、成员创建、收入登记在 320px 下检查，标题、滚动内容和底部取消/确认没有越界。
- 登录/权限/失败：独立本地匿名场景显示登录；密码按钮 44×44；仅库存权限账号无法访问利润，恢复入口确实进入库存，“我的”只显示 canonical 授权入口；读取失败可显示原因和重试。未登录真实账号，未修改权限或创建成员。
