# 账务防漂移第一阶段

## 目标

把 ERP 的账务边界固定为：

`业务单据 -> 资金事件 -> 账户流水 / 财务流水 -> 单据与报表投影`

本阶段只增加校验和只读体检，不改历史数据、不自动修复生产账、不重写现有业务单据流程。

## 已落地的边界

- 退货退款只能使用 `采购退款` 或 `客户退款`，不能写入 `其他收入` / `其他支出`。
- 进货退货退款必须是收入方向、财务金额为正；销售退货退款必须是支出方向、财务金额为负。
- 非经营收入、非经营支出不能绑定销售单、采购单、退货单或售后单。
- 账户流水和财务流水由同一处边界校验，避免两个账本出现不同分类。
- 财务核对页增加手动“检查账务”动作，不在页面打开时全量加载历史，避免影响日常使用。

## 体检内容

`GET /api/finance/reconciliation?limit=200` 受 `finance` 菜单权限保护，并按企业/门店加载完整快照，只读检查：

- 账户流水的前后余额链、收入/支出/净变动、可用余额。
- 收款/付款与账户流水、财务流水的显式关联、金额、方向和单据号。
- 销售/采购单的已收、已付、未收、未付金额。
- 退货单与退款、账户流水、财务流水的一对一关系。
- 非经营收支是否错误绑定业务单据。

体检报告中的 `error` 需要处理，`warning` 用于旧数据的隐式关联或实盘差异提示。体检本身不会改账。

## 后续顺序

1. 给体检异常增加逐条详情和导出/处理入口。
2. 将收付款、退货、销售、采购统一收敛到业务事件与不可变分录。
3. 对已完成单据关闭直接编辑，统一使用冲销/作废并保留原始凭证。
4. 增加月结锁定和月结后更正单，最后再做历史数据的人工确认迁移。
